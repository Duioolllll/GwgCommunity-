# 제출용 소스 및 구현 현황

기준일: 2026-11-17 (한국 시간). 사용자가 제공한 `gwg-commented-source-complete/annotated` 스냅샷을 기준으로 작성했다.

## 실행 구현과 이전 구현

- `pynext_app/`: 현행 PyNext 요청 처리와 Django ORM·폼·템플릿·업무 로직.
- `python_app/`: 독립 Django 이전 구현 및 가져오기·비교 도구.
- `next_engine/`: Next.js 이전 구현 및 비교·복구용 소스.
- `deploy/`, `Dockerfile`, `.github/workflows/`: 실행·프록시·CI 설정. GitHub 업로드가 운영 배포 성공을 뜻하지는 않는다.

## 주석 읽는 방법

기존 기능 설명을 보존하고 함수·클래스, if/elif의 참·거짓 결과, 반복, 예외 처리, 삼항 선택과 단락 평가에 주석을 추가했다. Python의 표현식 분기는 파일 머리의 목록에서, 문장 분기는 해당 코드 바로 위에서 설명한다. TypeScript/TSX의 표현식·화면 분기 설명은 해당 식을 포함하는 문장 바로 위에 모았다. 주석에 나온 반환·예외·대입 구문은 실제 처리와 대응한다.

Python 내장 Django 템플릿은 문자열을 바꾸지 않고 `template_source.py` 머리에 if/elif/else/for/empty 화면 분기를 설명했다. 생성된 PyNext 라우트와 테스트·마이그레이션 Python도 포함한다. CSS의 화면 너비 조건과 SQL 마이그레이션 작업에도 설명을 보강했다. 잠금 파일·JSON 메타데이터·외부 의존성과 해시 기반 생성 번들은 실행 기능 주석 대상이 아니다.

## 검증 범위

`submission-coverage.json`은 파일별 함수·분기 수와 정적 검사 결과다. 제공 스냅샷 대비 Python AST 및 주석 제외 토큰이 동일하고 모든 Python 파일의 메모리 컴파일을 확인했다. TypeScript/TSX/JS 설정 파일은 TypeScript 5.9.3 파싱과 주석 제외 프린터 출력 동일성을 확인했다. 따라서 주석 보강 과정의 실행 코드 변경 여부를 검사했다. 이전 GitHub main과의 차이는 사용자가 제공한 스냅샷 반영도 포함한다.

DB·SMTP·R2 및 운영 비밀값이 없는 로컬 환경이므로 전체 실행·통합·브라우저·배포 성공은 확인하지 않았다. 과거 스냅샷의 검증 문서는 해당 시점 기록이며 이번 검증과 구별한다. 자격증명·실제 환경 파일·DB·업로드, 로컬 IDE 설정, 해시 기반 `.pynext` 빌드 캐시는 제출본에 포함하지 않는다.

추가 실행 검증: 기존 Next Finder 매칭 단위 테스트 5개가 모두 통과했다. 정규화·잘못된 날짜·날짜 점수·70점 경계·후보 중복 제거·정렬·제한을 확인했다.
