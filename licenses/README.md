# Design asset notices

The service icons in `src/components/ServiceIcon.tsx` use artwork from [Lucide](https://lucide.dev/) and [Lucide Animated](https://lucide-animated.com/). The Finder and Clubs hover animations in `src/app/globals.css` adapt the search and users animations from Lucide Animated to CSS. The Market icon is derived from Lucide's shopping-bag icon.
